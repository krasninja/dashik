# Dashik

Dashik is the small local desktop widgets-based dashboard software.

*Note: The project is under development*

## Features

1. Works locally under Windows, macOS and Linux operating systems.
2. Group widgets under different spaces.
3. Every widget can be setup individually, and the settings are stored locally.

## Widgets

1. **GitHub Issues Widgets**. Shows list of assigned issues and PR from GitHub.
2. **CPU**. Shows current CPU usage.
3. **Memory**. Shows current memory usage.
4. **Red Eye**. Notifies that you should take a rest for your eyes.
5. **Clock**. Shows current time.
